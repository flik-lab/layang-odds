# QoS editor

The QoS editor configures per-topic DDS behavior.

Common QoS fields include:

- reliability
- durability
- history kind
- history depth
- deadline
- latency budget
- liveliness
- lease duration
- lifespan
- partition
- ownership

## Recommendation

Keep default QoS for basic smoke tests. Adjust QoS only when matching a real DDS participant or reproducing a field issue.
