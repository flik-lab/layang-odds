# Layang ODDS v1.0.0 public documentation release

This is the first public documentation release for Layang ODDS.

## Status

- Public repository: documentation and release notes only.
- Binary release: optional and may be distributed separately.

## Highlights

- Native CEF + OpenDDS desktop workflow.
- DDS topic discovery.
- Imported IDL workspace.
- DDS Runtime Build status flow.
- DDS Listener and Dynamic subscriber modes.
- JSON publish once.
- Scenario stream runner.
- Per-topic QoS editor.
- Topic identity based on domain id, topic name, and type name.

## Known limitations

- DDS/OpenDDS runtime setup depends on the operator environment.

Layang ODDS is currently released as public documentation while source code remains private during early production hardening.

## OpenDDS environment

OpenDDS can be configured from a user env file or a system-wide env file.

User config, recommended:

```bash
mkdir -p ~/.config/layang-odds
nano ~/.config/layang-odds/env
```

System-wide config:

```bash
sudo mkdir -p /etc/layang-odds
sudo nano /etc/layang-odds/layang-odds.env
```

Example content:

```dotenv
OPENDDS_ROOT=/opt/OpenDDS-3.29.1
LAYANG_ODDS_DDS_CONFIG=$HOME/.config/layang-odds/rtps.ini
```

Restart Layang ODDS after editing the env file.
